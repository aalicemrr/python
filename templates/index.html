Aula 4 de Flask

Seja bem-vindo! Neste projeto, nosso site é estruturado em torno das seguintes páginas principais: Home, Sobre Mim, Sobre Aulas e Sobre Ser Estudante de TI.

Nesta Aula 4, estamos desenvolvendo um menu de navegação dinâmico para conectar todas as páginas do nosso sistema Flask. O objetivo é aplicar os conceitos de rotas e templates que já aprendemos, criando uma barra de links que permite ao usuário navegar facilmente entre os conteúdos.

Para fazer isso, estamos centralizando a estrutura visual do menu dentro do arquivo layout.html. Dessa forma, usamos o conceito de herança de templates para que todas as páginas herdem esse mesmo menu automaticamente, evitando a repetição de código HTML e facilitando a manutenção do site.
